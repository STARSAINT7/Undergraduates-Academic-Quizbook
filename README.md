🎓 Academic Quizbook - University 100 Level
An advanced, fully responsive, single-file Computer-Based Testing (CBT) web application engineered specifically for university undergraduates. Built entirely with vanilla front-end technologies (HTML5, CSS3, and JavaScript), this platform simulates a professional academic testing environment across 27 core university 100-level courses.

✨ Key Features
Comprehensive Course Coverage (27 Courses): Includes curated questions for Sciences, Social Sciences, Management & Law, Arts & Humanities, and General Studies (GST 101–108 courses like Use of English, Philosophy & Logic, Nigerian Peoples & Culture, and ICT).

Robust Question Bank: Each subject features 50 distinct, randomized questions with dynamic option shuffling to ensure a fresh test experience every time.

Timed Examination Mode: Integrated 30-minute countdown timer with automatic submission upon expiration.

Interactive Test Interface:

Real-time progress bar tracking and question-status tracker.

Instant visual feedback (correct/wrong color highlights) upon option selection.

Fully accessible custom in-page dialog modals (bypassing browser alert blocks).

Detailed Performance Analytics: End-of-test grading screen providing absolute scores, percentage metrics, and personalized motivational feedback tailored to the student's score tier.

Single-File Architecture: Zero external dependencies or complex backend setup requirements—runs locally in any modern browser or can be hosted instantly via GitHub Pages.

🚀 Built With
HTML5 – Semantic structure and responsive layout containers.

CSS3 – Dynamic animated gradients, glassmorphism UI styling (backdrop-filter), and CSS Grid/Flexbox layouts.

Vanilla JavaScript (ES6+) – Complete state management, timer loops, array randomization algorithms, and dynamic DOM rendering.
